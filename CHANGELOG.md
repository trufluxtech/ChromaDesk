# Changelog

All notable changes to ChromaDesk are documented here.

## 0.4.2 - 2026-08-01

- Added a guided macOS installer that builds, verifies, installs, and opens ChromaDesk.
- Added automatic Homebrew dependency checks and a reusable drag-to-Applications DMG.
- Preserved existing installations as timestamped backups during upgrades.
- Added a branded Desktop shortcut workflow and native macOS application icon.

## 0.4.1 - 2026-08-01

- Added the transparent 1024 x 1024 ChromaDesk PNG logo.
- Added multi-resolution `.icns` resources and a safe macOS shortcut installer.

## 0.4.0 - 2026-08-01

- Added local Dust / Spot Heal and Clone Stamp tools as non-destructive layers.
- Added opt-in, prompt-based Generative Fill for marked areas.
- Added session-only OpenAI API-key handling and explicit upload consent.
- Added retouch serialization and processing tests.

## 0.3.9 and earlier

- Established the Qt/C++ non-destructive editor, local catalog, adjustment layers,
  AI-assisted masks, text and watermark layers, borders, guides, crop presets,
  passport sheets, 50 creative filters, themes, and Windows/macOS packaging.
